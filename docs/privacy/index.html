Summary

ElecPilot is designed to work entirely on your device. The developer collects no analytics, runs no ads, and operates no server. Your data stays on your device.

Data Stored on Your Device

ElecPilot stores the following data locally in app-private storage on your device:

  • Motor starters — electrical motor data (workshop, position, power, type, cable specifications)
  • PLC I/O modules — PLC card data (workshop, card, position, designation)
  • Favorites — your starred items
  • Settings — app preferences and configuration

None of this data is sent to the developer or any external server.

Voice Search

ElecPilot uses Android's built-in SpeechRecognizer for voice search. This uses your device's system speech recognition service. The app does not record audio, store voice data, or access your microphone directly. Voice input is handled entirely by the Android operating system.

Backup and Restore

Local Backup

You can export your data as Excel (.xlsx) or CSV (.csv) files to a folder you choose on your device, including cloud storage connected to your device. That data is handled by Android and the storage provider you select, not sent to a server run by the developer.

Cloud Backup

Cloud backup was removed in version 6.5.3. Earlier versions could connect a cloud storage provider directly from the app; that feature no longer exists, and the current version requests no cloud account access and makes no cloud connection.

Two notes for people upgrading from an earlier version:

  • Backup files you created with an earlier version remain where they are — in the cloud account you connected at the time — and stay readable there. This app no longer reads or modifies them.
  • The encrypted credential file that earlier versions wrote into the app's private storage may still be present after upgrading. The current version never reads it and never transmits it. Uninstalling the app removes it, and clearing the app's storage from Android Settings removes it too.

Permissions

ElecPilot requests the following permissions:

  • Internet — for checking and downloading app updates from GitHub Releases
  • Access Network State — to check connectivity before network calls
  • Post Notifications — declared in the manifest but not used by the current version; the app shows no notifications
  • Request Install Packages — needed only to install in-app updates that you explicitly accept

The app does not request access to your camera, contacts, location, or any other sensitive data.

Third-Party Services

The only third-party service ElecPilot contacts is GitHub, to check for app updates (comparing the latest release with your installed version) and, if you accept an update, to download the new APK from GitHub Releases. These requests carry no personal data. The developer does not operate any server that processes your data.

Storage providers you select yourself when exporting or restoring a backup — including a cloud storage app connected to your device — are chosen and controlled by you, and Android mediates the transfer. Their own privacy policies apply to them, not to ElecPilot.

Security

  • All data is stored locally in your device's app-private storage
  • No data is transmitted to the developer's servers (the developer operates no servers)
  • Network security configuration blocks cleartext (HTTP) traffic to every host

No Analytics or Tracking

ElecPilot does not include analytics, advertising, crash-reporting, or telemetry SDKs. The developer does not receive information about how you use the app.

Your Rights

You have full control over your data:

  • Access — all your data is visible within the app
  • Deletion — you can delete any data from within the app, or uninstall the app to remove all data
  • Export — you can export your data at any time via local backup

Since all data is stored locally on your device, the developer has no access to your data and cannot delete it on your behalf — you manage it directly through the app or by uninstalling.

Children

The app is not directed at children under 13, and the developer does not operate any service that collects personal information from children.
